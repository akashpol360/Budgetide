Privacy Policy for Budgetide

Last updated: September 1, 2026

Budgetide ("the app") is a personal finance tracker built to work fully offline. This policy explains what happens to your data when you use it.

Data collection

Budgetide does not collect, transmit, or share any personal data. The app has no backend server, no analytics SDK, no advertising SDK, and does not require an internet connection to function.

Where your data is stored

All information you enter — transactions, goals, recurring payments, warranties, and lending/borrowing records — is stored only in a local database on your own device, inside the app's private storage. Anthropic, the developer, and any third party never see this data.

Backups you create

The app includes an optional "Export backup" feature. When you use it, a JSON file containing your data is written only to a location you choose on your own device (or a cloud-storage folder you pick, such as Google Drive), using Android's standard file picker. Budgetide does not upload this file anywhere itself. You are responsible for keeping any exported backup file secure, since it contains the same financial details you entered in the app.

Permissions

Budgetide does not request camera, contacts, location, SMS, or any other sensitive Android permission. Backup export/restore uses Android's built-in file picker (Storage Access Framework), which does not require a broad storage permission.

Children's privacy

Budgetide does not knowingly collect data from anyone, including children, because it does not collect data at all.

Changes to this policy

If this policy changes — for example, if a future version of the app adds optional cloud sync — this page will be updated and the "Last updated" date above will change accordingly.
